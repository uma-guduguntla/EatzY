# 🍽️ EatzY

EatzY is a modern food delivery web app concept — clean, fast, and built for simplicity.  
Designed for students, professionals, and anyone who wants food delivered fresh and quick.

---

## 🚀 Features
- 🥗 Daily meal plans (Breakfast, Lunch, Dinner)
- 💸 Affordable subscriptions
- 🔔 Real-time delivery tracking (UI concept)
- 💡 Smooth animations and responsive layout

---

## 🧠 Tech Stack
- **HTML5** – Structure  
- **CSS3** – Styling and responsive design  
- **JavaScript (Vanilla)** – Interactivity
